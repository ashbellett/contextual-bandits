Contextual bandits with Gaussian-process rewards

An agent repeatedly sees a context, picks one of several arms and observes a noisy reward. It never sees the reward curves; it learns them with one Gaussian process per arm and chooses arms by Thompson sampling. The second experiment changes the curves twice without warning.

Method

  1. A context x is drawn uniformly from [0, 1].
  2. For each arm a, the agent draws one sample of the arm's mean reward μa(x) from its Gaussian-process posterior, and pulls the arm with the largest sample.
  3. It observes r = μa(x) + ε with ε ~ N(0, σ²) and adds (x, r) to that arm's data.
  4. Regret for the round is maxa′ μa′(x) − μa(x): the expected reward lost by not pulling the best arm for this context.

Each Gaussian process uses a Matérn-5/2 kernel whose signal variance, length scale and noise variance are learned by maximising the marginal likelihood. Under change points, a sliding window keeps only the observations from recent rounds, so arms that have not been pulled lately become uncertain again and get re-explored.
